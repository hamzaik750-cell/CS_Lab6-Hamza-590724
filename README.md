# Storage Estimator

## Purpose
A small Python program that estimates how much storage is needed for a set of
files, based on the number of files and their average size. Built for CS-117
Introduction to ICT (Lab 10) and used in Lab 11 to practise Git and GitHub.

## How to run
1. Install Python 3.
2. Open a terminal in this folder and run:

```
python storage_estimator.py
```

(Use `python3` instead of `python` on Mac/Linux.)

## Example
Input and output:

```
=== Storage Estimator ===
Number of files: 120
Average file size (MB): 2.5
Total storage needed: 300.00 MB
```
